# CRM АвтоБрокер

CRM для автоброкера на Python (Flask + SQLite). Работает в браузере, все данные хранятся у вас в файле `data/crm.db`.

## Запуск

1. Нужен **Python 3.10+** ([python.org](https://www.python.org/downloads/)), при установке отметьте **Add python.exe to PATH**.
2. Дважды кликните **`run.bat`**. Он сам установит Flask и откроет CRM в браузере: http://127.0.0.1:5000
   В PyCharm можно просто запустить `main.py` (Shift+F10), предварительно выполнив `pip install -r requirements.txt`.
3. При первом запуске CRM попросит создать **администратора**. Можно сразу отметить «Заполнить демо-данными», чтобы посмотреть всё в работе.

### Работа с сотрудниками в одной сети

Запустите **`run_lan.bat`**. В окне появится адрес вида `http://192.168.1.10:5000`. Его открывают сотрудники со своих компьютеров и телефонов в той же Wi-Fi или локальной сети. Если не открывается, разрешите Python в брандмауэре Windows.

## Доступ и роли

Регистрации нет. **Только администратор** создаёт сотрудников («Сотрудники и доступ»), задаёт логин и пароль (есть генератор) и после сохранения видит карточку с данными для входа и кнопкой «Скопировать». Пароли хранятся в базе только в виде хэша.

| Роль | Что может |
|---|---|
| Администратор | Всё, включая сотрудников, настройки, удаление, резервную копию |
| Менеджер | Клиенты, сделки, склад, прокат, задачи, календарь, документы (без удаления и настроек) |
| Наблюдатель | Только просмотр (для инвестора или партнёра) |

Сотрудника можно заблокировать галочкой «Доступ включён». Каждый может сменить свой пароль, нажав на своё имя внизу меню.

## Разделы

- **Дашборд**: кому позвонить, задачи, прокат на сегодня, показатели (машины в наличии, склад в продаже, ожидаемая маржа, загрузка проката, бюджеты в работе), воронка, выручка проката за 6 месяцев, заявки по направлениям.
- **Задачи**: группы «Просрочено / Сегодня / Неделя / Позже», приоритеты, исполнители, галочка выполнения без перезагрузки.
- **Календарь**: месяц с задачами, встречами, звонками, выдачей и возвратом авто, сроками сделок. **Мини-календарь в левом нижнем углу** меню показывает дни с событиями.
- **Клиенты**: при создании выбираете, что нужно клиенту: заказ авто из **Китая / Японии / Кореи**, **подбор**, **продажа**, **покупка (выкуп)**, **комиссия**, **прокат**. По каждой услуге создаётся сделка в воронке. В карточке есть история, комментарии, звонки, «перезвонить», сделки, задачи, документы. Экспорт в Excel (CSV).
- **Воронка сделок**: канбан, карточки перетаскиваются мышкой между этапами. Фильтр по направлению и «только мои».
- **Склад**: все авто, склад, Китай/Япония/Корея (в пути), выкуп, комиссия, проданные. Фото, VIN, госномер, закупка, расходы, цена, автоматический расчёт маржи. Плитка или таблица.
- **Прокат**: график занятости автопарка (клик по клетке оформляет аренду), проверка пересечения дат, расчёт суммы, залог, пробег, статусы. Авто автоматически получает статус «В прокате».
- **Договоры и акты**:
  - **Договор-заявка** и **Акт осмотра**: ваши бланки из папок «Договор - программа» и «Акт осмотра - программа». Открываются внутри CRM с уже подставленными ФИО, телефоном, паспортом, авто, VIN, и сохраняются в базу автоматически.
  - **Договор проката** и **Акт приёма-передачи**: заполняются из аренды, клиента и авто. Жёлтые поля можно править прямо на листе.
  - Всё печатается на A4 или сохраняется в PDF.
- **Ценники**: вертикальный и горизонтальный A4 (ваши конструкторы CHI AUTO). Выбираете авто со склада, и марка, модель, год, пробег, двигатель, КПП, привод, цвет и цена подставляются сами. Кнопка «Ценник» есть и в карточке авто. Сохранение в PDF и печать, как раньше.
- **Чат**: личные сообщения любому сотруднику, группы («Продажи», «Привоз из Китая»…), отправка фото и файлов, непрочитанные в меню и в колокольчике. Группу может переименовать, пополнить и удалить её создатель или администратор, выйти может любой участник.
- **Фото сотрудников**: администратор загружает фото в карточке сотрудника, сотрудник может поставить своё сам в профиле (клик по имени внизу меню). Фото видно в чате, задачах, сделках и списках.
- **Поиск** (Ctrl+K): по ФИО, телефону (любая часть цифр), VIN, госномеру.
- **Уведомления** (колокольчик): просроченные задачи, звонки, возвраты авто из проката.
- **Тёмная тема**: кнопка с луной.

## Файлы

```
app.py            — вся логика и страницы
db.py             — база данных и справочники (типы сделок, этапы, статусы)
seed.py           — демо-данные
templates/        — HTML-шаблоны страниц
static/           — стили, скрипты, логотип, копии бланков, ценники (static/tags)
data/crm.db       — ВАША БАЗА (делайте копии: «Настройки → Скачать резервную копию»)
run.bat / run_lan.bat / main.py — запуск
```

Этапы воронки, типы сделок, источники клиентов и статусы авто меняются в начале `db.py`.
